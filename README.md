## Public code

### [Damk 3alena — blood donation forecasting and matching](https://github.com/S3doz00/Damk-3alena)

Graduation team project for donor and hospital workflows in Jordan. The prototype joins a React Native donor app, React dashboard, Supabase/PostgreSQL backend, and FastAPI AI service. Its models forecast weekly demand with XGBoost quantile regression, detect shortages, and rank donor recommendations. I worked on the integrated AI and software prototype.

`React Native` `React` `TypeScript` `Supabase` `FastAPI` `Python` `XGBoost`

### [Freight rate prediction assessment](https://github.com/S3doz00/freight-rate-prediction-assessment)

Reproducible Python pipeline for freight rate prediction. It uses forward monthly holdouts, compares regression approaches, handles missing values, and produces validation and December predictions in the required output format. The published README reports a pooled holdout MAE of **$104.37** across 14,282 rows; final hidden evaluation labels are unavailable.

`Python` `pandas` `scikit-learn` `time-aware validation`
